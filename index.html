À propos · Toulouse

Zakir Asadov

J’aime comprendre comment les choses fonctionnent, puis construire les miennes. J’ai commencé à programmer seul, projet après projet : le shell Linux, le C, puis le JavaScript avec mes extensions.

Ma façon de construire

Un vrai problème, une solution qui tient.

Mes idées naissent presque toujours d’une gêne que je rencontre : un texte en anglais à comprendre vite, une manipulation répétée dix fois par jour, un outil qui pourrait être plus simple.

Je préfère une première version qui marche à un plan parfait. Ensuite, je teste, je corrige et je soigne les détails.

  1. 01

    Partir d’un vrai besoin

    Une gêne réelle, et une question simple : que doit prouver la première version ?

  2. 02

    Prototyper vite

    Une version qui fonctionne dans le navigateur, même brute, pour tester l’idée en conditions réelles.

  3. 03

    Finir proprement

    Interface, vitesse, cas particuliers : je reprends jusqu’à ce que l’outil soit agréable au quotidien.
